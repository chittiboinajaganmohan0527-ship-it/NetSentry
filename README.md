
# NetSentry
## Network Intrusion Detection and Alert System

### About the Project
NetSentry is a Python-based project that demonstrates network monitoring and detection of potentially suspicious activity.

### Features
- Network event monitoring
- Simulated normal and suspicious events
- Rule-based alert generation
- TCP and UDP communication demonstrations
- Dashboard for viewing events and alerts
- Event history and reporting

### Technologies
- Python
- Flask
- HTML and CSS
- SQLite

### Team
Developed as a Computer Networks Systems (CNS) academic project.
